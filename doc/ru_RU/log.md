Лог как не странно логирует (да ладно!?).  
Он -- отдельная глобальная таблица log (`_G.log`).  
Вы можете вызывать эту таблицу напрямую (у него есть мета).  

### Агрументы вызова
Так... `log(event_log: table [, list_of_events: bool])`,  
Где:
- event_log -- таблица. Само событие логирование, содержит некоторые штуки (без ключей, лишь значения)
	1. date, нужен только для листов событий (об этом ниже), иначе будет ошибка. Просто не ставьте его если это не лист. Number
	2. level, уровень логирования. Number (целое). Всего существует... немного уровней:
		1. DEBUG (Первый уровень, 1)
		2. INFO (Второй уровень, 2)
		3. WARNING (Третий уровень, 3)
		4. CRITICAL (Четвёртый уровень, 4)
		5. ERROR (Пятый уровень, 5)
	3. Сообщение события. Несёт главную информацию. String
- list_of_events (необязательный) -- Bool. Является ли event_log листом событий? Если да, то да и должен быть там ещё date; если нет, то там одно событие

Примеры:
- `log({2, "Successfully startup"})`
- `log({{0.7, 1, "TEST DEBUG MESSAGE"}, {1, 5, "TEST ERROR"}}, true)`

## buffer
Как ни странно мы рекомендуем использовать буффер (иначе у вас всё будет очень сильно лагать).  
Для этого в данном core module есть так называемый buffer (что в переводе означает буфер..) (*log.buffer*);  
Вы его можете использовать! Вот небольшая API-шка:
- **log.buffer.add()** -- буквально образ и подобие log(), но записывает в буфер. Документация этого log выше
- **log.buffer.push()** -- push-ает буфер на всё что можно. То есть производит по сути log(log.buffer(), true) и сбрасывает буфур до нулевого состояния
- **log.buffer()** -- Возвращает накопленный буфер

При чём push-ать буфер вам зачастую не надо, за вас это сделают главные скрипты ([init](/src/init.lua) или [main](/src/main.lua) в зависиммости от ситуации)

И... Это всё! Да, вот так просто, как и идея буфера, да и реализация тоже проста там.  

Примеры:
- `log.buffer.add({4, "WOW, IT'S BUFFERED LOG!!"})`
- `log.buffer.add({{259, 4, "Your log message 1 there"}, {330, 2, "Your log message 2 there. So there are can be more events"}}, true)`
- `log.buffer.push()`
