Лог как не странно логирует (да ладно!?).  
Он -- отдельная глобальная таблица log (`_G.log`).  
Вы можете вызывать эту таблицу напрямую (у него есть мета).  

### Агрументы вызова
Так... `log(event_log: table [, list_of_events: bool])`,  
Где:
- event_log -- таблица. Само событие логирование, содержит некоторые штуки (без ключей, лишь значения)
	1. date, нужен только для листов событий (об этом ниже), иначе будет ошибка. Просто не ставьте его если это не лист. Number
	2. level, уровень логирования. Number (целое). Всего существует... немного уровней:
		1. DEBUG (Первый уровень, 1)
		2. INFO (Второй уровень, 2)
		3. WARNING (Третий уровень, 3)
		4. CRITICAL (Четвёртый уровень, 4)
		5. ERROR (Пятый уровень, 5)
	3. Сообщение события. Несёт главную информацию. String
- list_of_events (необязательный) -- Bool. Является ли event_log листом событий? Если да, то да и должен быть там ещё date; если нет, то там одно событие

Примеры:
- `log({2, "Successfully startup"})`
- `log({{0.7, 1, "TEST DEBUG MESSAGE"}, {1, 5, "TEST ERROR"}}, true)`
